# カメムシバスター

近未来風の60秒タイピングゲーム。画面に表示される日本語を英語にして Enter で攻撃します。

## プレイ

1. 名前を入力して START。
2. 3・2・1 の後、60秒間でできるだけ多くのロボットカメムシを倒します。
3. 結果は「○匹」で表示され、ランキング、Replay、単語一覧を確認できます。

ゲーム中は `battle100.mp3` がループ再生され、撃破時に `hit.mp3` が鳴ります。誤答時はカメムシが赤く光り、画面が少し揺れます。画面右上の音アイコンから効果音と BGM をそれぞれオン・オフできます。音設定はブラウザに保存されます。

## 管理者の単語登録

画面右上の歯車から CSV を読み込めます。Google スプレッドシートでは「ファイル → ダウンロード → カンマ区切り形式 (.csv)」、Excel では「名前を付けて保存 → CSV UTF-8」を選びます。

| 行 | A列（英語） | B列（日本語） |
| --- | --- | --- |
| 1 | English | Japanese |
| 2 | apple | りんご |
| 3 | future | 未来 |

1行目は見出しとして読み飛ばし、2行目以降の A・B 列だけを登録します。ゲーム画面には B列のみ表示します。読み込みは既存の単語を置き換えます。管理者キーは Sites の環境変数 `ADMIN_KEY` に保存され、GitHub のソースには含みません。

管理者画面では同じキーを入力してランキングを全件削除できます。削除ボタンは誤操作を防ぐために2回押して確定します。削除した記録は復元できません。

## 構成

- `worker/page.html`, `style.css`, `app.js`: 画面とゲーム処理
- `worker/index.js`: API と静的配信
- `worker/music/battle100.mp3`: ゲーム中の BGM
- `worker/music/hit.mp3`: 撃破時の効果音
- `drizzle/0000_initial.sql`: D1 の単語、プレイ、ランキング
- `.openai/hosting.json`: Sites の設定

ランキングは Cloudflare D1 に保存されます。GitHub Pages 単体にはサーバーと D1 がないため、このリポジトリはソース公開用で、プレイ用 URL は Sites のデプロイ URL です。
